🌟 Самостояйка (Samostoyayka)

Интерактивный список дел для детей, созданный для развития самостоятельности и закрепления полезных привычек (например, утренние сборы в школу или вечерняя рутина).

Проект представляет собой MVP (минимально жизнеспособный продукт) мобильного приложения, разработанного с использованием современных подходов Microsoft.

🛠 Технологии и инструменты

Язык: C#

Фреймворк: .NET MAUI (Multi-platform App UI)

Архитектура: MVVM (Model-View-ViewModel)

База данных: SQLite (локальное хранение данных)

Библиотеки:

CommunityToolkit.Mvvm (для реактивного UI: ObservableObject и RelayCommand)

sqlite-net-pcl (для ORM работы с БД)

✨ Реализованный функционал (MVP)

[x] Полный CRUD цикл для задач (создание, чтение, обновление, удаление).

[x] Динамический UI: автоматическое перемещение задач между списками "Осталось сделать" и "Готово" при отметке чекбокса.

[x] Локальное сохранение: данные и статус выполнения не теряются при перезапуске приложения благодаря встроенной базе данных SQLite.

[x] Data Binding: двусторонняя привязка данных и обновление интерфейса в реальном времени.
